1. LIVING CONTROL CHAMBER (Agent Living Popup)
============================================================================

Location: src/components/agent/AgentLivingPopup.tsx

This is a MAJOR enhancement over the basic agent popup in the old frontend.

UNIQUE FEATURES:
----------------
a) Real-Time API Integration
   - Connected to /api/agent/status for live agent state
   - Connected to /api/activity/timeline for real cognitive stream
   - Automatic sync with backend (not just mock data simulation)

b) Morphing Layout System
   - Container morphs smoothly when interventions appear
   - Upper zone (presence + time) shrinks during intervention
   - Lower zone (cognitive stream) dims during focus moments
   - All transitions use cubic-bezier easing for organic feel

c) Time Flow Ring Integration
   - Circular temporal visualization showing:
     * Past events (faded markers)
     * Current "now" marker (highlighted)
     * Approaching events (future markers)
   - Visual importance indicators (low/medium/high)
   - Scales down during interventions to focus attention

d) Intervention Layer System
   - Full-screen overlay when agent needs attention
   - User can respond with quick actions or dismiss
   - Responses are logged back to cognitive stream
   - Agent state transitions based on user response

e) Session Timer
   - Elapsed time counter in top-left
   - Shows how long the popup has been open
   - Useful for tracking observation sessions

f) Cognitive Activity Stream
   - Live stream of agent thoughts from API
   - Fallback simulation when API returns no data
   - Type-coded entries (observation, evaluation, decision, action, waiting)
   - Animated entry/exit for thoughts

8. BEHAVIOR TRACKING SYSTEM
============================================================================

Location: src/hooks/useBehaviorTracking.ts

Advanced user behavior analysis:

UNIQUE FEATURES:
----------------
a) Flow State Detection
   - Monitors mouse, keyboard, click activity
   - Calculates inactivity duration
   - Detects deep focus (>15min, <120s inactivity, <2 skips)

b) Session Mood Classification
   - productive: focus > 25min
   - struggling: inactivity > 300s
   - neutral: default state
   - calm: light activity

c) Task Interaction Tracking
   - recordTaskSkip() - tracks avoidance
   - recordTaskComplete() - boosts consistency

d) Consistency Scoring
   - 0-100 scale
   - Increases with completions
   - Decreases with skips
