# 1. PROJECT OVERVIEW
# ═══════════════════════════════════════════════════════════════════════════════

Project Name: NEBUNEX
Description: A personal life operating system with an intelligent AI agent that 
             monitors productivity, health, finances, and provides proactive 
             interventions and insights.

Key Features:
- Dashboard with productivity scoring and streak tracking
- Project management with CRUD operations
- Kanban-style task management
- AI Agent with living presence (visual orb, cognitive stream)
- Proactive agent interventions with wellness checks
- Time-aware scheduling visualization
- Behavior tracking (flow state detection)

# 3. BACKEND CONNECTION SETUP
# ═══════════════════════════════════════════════════════════════════════════════

The frontend connects to a FastAPI backend running on port 3847.

CONNECTION METHOD: Vite Dev Server Proxy
----------------------------------------

vite.config.ts:
```typescript
proxy: {
  "/api": {
    target: "http://localhost:3847",
    changeOrigin: true,
  },
}
```

API Service (src/services/api.ts):
```typescript
const BASE = import.meta.env.VITE_API_BASE ?? '/api';
// All requests go through `/api` and get proxied to backend
```

IMPORTANT RULES:
1. Use relative paths ('/api') NOT absolute URLs
2. Proxy handles CORS automatically
3. Restart dev server after config changes
4. Backend must be running on port 3847

API ENDPOINTS SUPPORTED:
------------------------
- GET  /api/dashboard             - Dashboard summary data
- GET  /api/projects              - List all projects
- POST /api/projects              - Create project
- PUT  /api/projects/:id          - Update project
- DELETE /api/projects/:id        - Delete project
- GET  /api/tasks/kanban          - Get tasks in kanban format
- POST /api/tasks                 - Create task
- PUT  /api/tasks/:id/move        - Move task between columns
- DELETE /api/tasks/:id           - Delete task
- GET  /api/productivity/score/today - Today's productivity score
- GET  /api/productivity/streak   - Current streak data
- GET  /api/tasks/daily/goals     - Daily goals
- GET  /api/agent/status          - Agent state
- GET  /api/activity/timeline     - Agent activity timeline

# 6. STATE MANAGEMENT & HOOKS
# ═══════════════════════════════════════════════════════════════════════════════

6.1 useDashboardData (src/hooks/useDashboardData.ts)
-----------------------------------------------------
Aggregates dashboard data from multiple endpoints.

Queries:
- /api/dashboard (30s stale, 60s refetch)
- /api/productivity/score/today (30s stale)
- /api/productivity/streak (60s stale)
- /api/tasks/daily/goals (30s stale)
- /api/projects?status=active (60s stale)

Returns:
- data: Merged dashboard data
- isLoading: Any query loading
- error: First error encountered
- refetch(): Refetch all queries


6.2 useAgentApi (src/hooks/useAgentApi.ts)
-------------------------------------------
Fetches agent status and timeline from backend.

Queries:
- /api/agent/status (5s refetch, 3s stale)
- /api/activity/timeline (8s refetch, 5s stale)

Returns:
- status: Raw status object
- agentState: Mapped to valid state enum
- thoughts: Timeline mapped to CognitiveThought[]
- isLoading, error, refetch


6.3 useAgentState (src/hooks/useAgentState.ts)
-----------------------------------------------
Client-side agent state simulation (fallback when no backend).

Features:
- Emotion cycling (8s interval)
- Random cognitive entries (25s interval)
- Mock anticipation items
- Trust level tracking

Returns:
- emotion, currentTask, isActive, trustLevel
- cognitiveTimeline: CognitiveEntry[]
- anticipations: AnticipationItem[]
- setEmotion(), setAnticipations()


6.4 useBehaviorTracking (src/hooks/useBehaviorTracking.ts)
-----------------------------------------------------------
Tracks user behavior for flow state detection.

Tracked Metrics:
- isInFlow: True if focused >15min, inactive <2min, skips <2
- focusDuration: Minutes since focus started
- inactivityDuration: Seconds since last activity
- sessionMood: calm, productive, struggling, neutral
- consistency: 0-100 score
- taskSkipCount: Number of skipped tasks

Activity Events: mousemove, keydown, click

Returns:
- behavior: BehaviorState object
- recordTaskSkip(): Increment skip count
- recordTaskComplete(): Boost consistency

# 7. API SERVICE LAYER
# ═══════════════════════════════════════════════════════════════════════════════

Location: src/services/api.ts

Core Function:
```typescript
async function request(path: string, options?: RequestInit) {
  const res = await fetch(`${BASE}${path}`, {
    headers: { 'Content-Type': 'application/json', ...options?.headers },
    ...options,
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({ detail: res.statusText }));
    throw new Error(err.detail || 'Request failed');
  }
  return res.json();
}
```

API Modules:
- api.dashboard() - Dashboard summary
- api.projects.* - Projects CRUD
- api.tasks.* - Tasks and Kanban
- api.tasks.goals.* - Daily goals
- api.productivity.* - Scores, streaks, heatmaps
- api.health.* - Wellness tracking
- api.finances.* - Transactions, budgets
- api.knowledge.* - Bookmarks, reading lists
- api.vault.* - Password vault
- api.freelance.* - Client management
- api.ai.chat() - AI chat messages
- api.agent.* - Agent status and chat
- api.search.query() - Global search
- api.notifications.* - Notification CRUD
- api.activity.* - Activity timeline
- api.users.* - User profile
- api.data.* - Export functionality

# 9. ANIMATIONS & INTERACTIONS
# ═══════════════════════════════════════════════════════════════════════════════

Animation Library: Framer Motion

9.1 PAGE TRANSITIONS
---------------------
- Initial: opacity 0, y 10-12px
- Animate: opacity 1, y 0
- Duration: 0.4-0.5s
- Easing: easeOut or custom bezier

9.2 LIST ITEMS
---------------
- Staggered delay: i * 0.05-0.08s
- AnimatePresence for add/remove
- Exit: opacity 0, scale 0.95

9.3 AGENT ANIMATIONS
---------------------
- Breathing: scale oscillation
- Rotation: continuous for layers
- Pulse: opacity + scale for alerts
- Blur: filter for thought transitions

9.4 INTERACTIVE ELEMENTS
-------------------------
- whileHover: scale 1.05-1.1
- whileTap: scale 0.95
- Transition: spring or custom ease

9.5 KEYFRAME ANIMATIONS (CSS)
------------------------------
- breathe: Scale + opacity pulse
- think: Scale + rotation oscillation
- concern: Scale + box-shadow pulse
- anticipateIn: Blur + translate + scale
- livingShift: Background position shift
- pulseSubtle: Simple opacity pulse
